# akl.run Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build akl.run — a static Astro 7 site: a project-hub window over a live, infinite pixel-art factory engine with event state machines and a journal — in a new repo seeded from `../akl.io`.

**Architecture:** Astro 7 SSG, one page (`src/pages/index.astro`). The engine is TypeScript modules under `src/factory/` bundled by Vite into one hashed module; CSS is `src/styles/main.css` bundled into one hashed stylesheet; `public/assets/js/boot.js` is a plain synchronous script. The world is an infinite grid of pure chunks (`(cx, cy, seed)` → raster pixels + feature list); a live layer and event machines run over it; a journal writes to the DOM.

**Tech Stack:** Astro 7.4, TypeScript 6, Vitest + jsdom, Nix flake (devenv, treefmt, flake checks), Playwright-core (acceptance only, outside nix), Cloudflare Pages.

**Read before any task:** `docs/superpowers/specs/2026-11-01-akl-run-design.md` (the design; overrides the handoff), `docs/handoff/README.md` (the product spec; `§n` below means a section of the handoff unless prefixed "spec"). Behaviour reference: `docs/handoff/reference/engine-reference.js` (cited as `ref:LINE`). Old engine: `../akl.io/public/assets/js/mapgen.js` (cited as `akl:LINE`).

## Global Constraints

- Node ≥ 22.22.0 (`engines`); toolchain Node 24 (`.node-version` = `24`, flake `nodejs_24`).
- CSP (unchanged from akl.io `public/_headers`): `script-src 'self'; style-src 'self' https://fonts.googleapis.com` — **no inline `<script>`** (except `application/ld+json`), **no `<style>`**, **no `style=`** anywhere in emitted HTML. JS may set `canvas.width/height`, classes and attributes; it must not write `el.style`.
- `boot.js` tag must be exactly `<script is:inline src={asset('assets/js/boot.js')}></script>`. The engine entry must be exactly `<script src="../factory/page.ts"></script>` (no other attribute).
- `src/pages/index.astro`: void elements without trailing slash; formatter-excluded; `compressHTML: false`.
- `world/**` must never import `core/rng` or `core/clock`, nor reference `Math.random`, `Date`, `performance`.
- No module may call `core/rng`, touch the DOM, or create a canvas at import time (module scope).
- All DOM hooks null-guarded; DOM text built with `textContent`/`createElement`, never by assigning HTML strings.
- Dark only. Copy, colours, sizes, timings: verbatim from the handoff unless the spec overrides.
- Tile `T = 6` px; chunk `CH = 32` tiles; chunk px `CPX = 192`; apron `AP = 3` tiles.
- Every commit message ends with this line (shown as `<TRAILER>` in the commit steps below — always expand it):
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  ```
- Work on branch `claude/akl-run`; never commit to `trunk`; never push.
- Sandbox note for workers: if a Bash command fails with "Read-only file system" or cannot write `.git`, re-run it with the sandbox disabled (`dangerouslyDisableSandbox: true`). Use the Write/Edit tools for file edits.
- Prettier `printWidth: 110` in `src/factory/**`, `src/styles/**`, `tests/**`.

```nix
{
  perSystem =
    { pkgs, self', ... }:
    {
      # Unit tests (vitest) against the locked deps; no network needed.
      checks.unit = pkgs.buildNpmPackage {
        pname = "akl-run-unit";
        version = "0.1.0";
        src = ./..;
        npmDeps = pkgs.importNpmLock { npmRoot = ./..; };
        npmConfigHook = pkgs.importNpmLock.npmConfigHook;
        nodejs = pkgs.nodejs_24;
        env.CI = "1";
        buildPhase = ''
          runHook preBuild
          npm test
          runHook postBuild
        '';
        installPhase = ''
          runHook preInstall
          touch $out
          runHook postInstall
        '';
      };

      # The CSP forbids inline script/style and the browser blocks them
      # silently; turn that into a build failure.
      checks.csp-output = pkgs.runCommand "csp-output" { } ''
        set -euo pipefail
        site=${self'.packages.default}
        status=0
        for f in $(find "$site" -name '*.html'); do
          if grep -q '<style' "$f"; then echo "csp-output: <style> in $f" >&2; status=1; fi
          if grep -q ' style=' "$f"; then echo "csp-output: style= in $f" >&2; status=1; fi
          if grep -oE '<script[^>]*>' "$f" | grep -v ' src=' | grep -vq 'application/ld+json'; then
            echo "csp-output: inline <script> in $f" >&2; status=1
          fi
        done
        grep -q 'boot.js?v=' "$site/index.html" || { echo "csp-output: boot.js missing" >&2; status=1; }
        n=$(grep -o '<script type="module" src="/_astro/' "$site/index.html" | wc -l)
        [ "$n" -eq 1 ] || { echo "csp-output: expected 1 module script, got $n" >&2; status=1; }
        [ "$status" -eq 0 ]
        echo ok > $out
      '';
    };
}
```

```ts
// Frozen contract shared by every src/factory module. Only the integrator
// edits this file; workers code against it.

export const T = 6; // world px per tile
export const CH = 32; // tiles per chunk side
export const CPX = T * CH; // 192 world px per chunk side
export const AP = 3; // apron tiles around a chunk (neighbour lookups only; never painted)

export interface Pt {
  x: number;
  y: number;
}
export interface Rect {
  x: number;
  y: number;
  w: number;
  h: number;
}
/** 0 = east, 1 = south, 2 = west, 3 = north. */
export type Dir = 0 | 1 | 2 | 3;
export const DIRS: readonly (readonly [number, number])[] = [
  [1, 0],
  [0, 1],
  [-1, 0],
  [0, -1],
];

export type DistrictKind =
  | "wild"
  | "outpost"
  | "mine"
  | "smelt"
  | "asm"
  | "power"
  | "hub"
  | "nest"
  | "labs"
  | "solar"
  | "oil"
  | "storage"
  | "silo";

/** CSS colour: '#rgb', '#rrggbb', '#rrggbbaa' or 'rgba(r,g,b,a)'. */
export type Color = string;

export type MachineKind =
  | "furnace"
  | "boiler"
  | "engine"
  | "drill"
  | "assembler"
  | "pumpjack"
  | "chem"
  | "refinery"
  | "flare"
  | "tank"
  | "lab"
  | "accumulator"
  | "lamp"
  | "pole"
  | "bigpole"
  | "roboport"
  | "radar"
  | "turret"
  | "chest"
  | "offshore"
  | "spawner"
  | "worm";

// ---- features (all coordinates are WORLD PX; w/h on Machine are TILES) ----

/** Ids are `${prefix}:${cx},${cy}:${n}` — stable for a given (seed, chunk). */
export interface Machine {
  id: string;
  kind: MachineKind;
  at: Pt; // centre
  w: number; // tiles
  h: number; // tiles
}
export interface BeltPath {
  id: string;
  pts: Pt[]; // tile centres in flow order; consecutive points are axis-aligned
  lanes: [Color[], Color[]]; // item colour mix per lane (left, right of flow)
}
export interface Inserter {
  id: string;
  at: Pt; // tile centre
  dir: Dir; // direction items are dropped
  fast: boolean;
  beltId: string | null; // belt it picks from / drops onto
  stationId: string | null; // set when within 34 px of a station
}
export interface RailSeg {
  id: string;
  a: Pt; // centre-line endpoints; axis-aligned
  b: Pt;
  lineId: string; // segments with equal lineId are one continuous line
}
export interface Station {
  id: string;
  at: Pt; // stop point on the rail centre-line
  lineId: string;
  vertical: boolean;
}
export interface RoadSeg {
  id: string;
  a: Pt;
  b: Pt;
  width: number; // tiles
}
export interface WallSeg {
  id: string;
  rect: Rect;
}
export interface SolarField {
  id: string;
  rect: Rect;
}
export interface NestSite {
  id: string;
  cx: number;
  cy: number;
  rect: Rect;
  spawners: Pt[];
  worms: Pt[];
  outpost: { cx: number; cy: number }; // the paired outpost chunk
}
export interface OutpostSite {
  id: string;
  cx: number;
  cy: number;
  rect: Rect; // wall ring outer rect
  wall: WallSeg[];
  turrets: Pt[];
  radar: Pt;
  roboport: Pt;
  facing: Dir; // DIRS[facing] points from outpost toward its nest
}
export interface HubSite {
  id: string;
  cx: number;
  cy: number;
  rect: Rect; // concrete pad
  roboport: Pt;
  lot: Rect; // 12×10 tile construction lot, empty in the pure chunk
  chests: Pt[];
  carPark: Pt;
  spiderPark: Pt;
}
export interface SiloSite {
  id: string;
  cx: number;
  cy: number;
  pad: Rect;
  at: Pt; // silo centre
  lights: Pt[]; // 4 pad lamps
}
export interface Features {
  belts: BeltPath[];
  inserters: Inserter[];
  machines: Machine[];
  rails: RailSeg[];
  stations: Station[];
  roads: RoadSeg[];
  solar: SolarField[];
  shore: Pt[]; // centres of water tiles adjacent to land
  nests: NestSite[];
  outposts: OutpostSite[];
  hubs: HubSite[];
  silos: SiloSite[];
}
export function emptyFeatures(): Features {
  return {
    belts: [],
    inserters: [],
    machines: [],
    rails: [],
    stations: [],
    roads: [],
    solar: [],
    shore: [],
    nests: [],
    outposts: [],
    hubs: [],
    silos: [],
  };

/** Centre of a w×h tile block whose top-left tile is (tx, ty), in world px. */
export function tileCentre(tx: number, ty: number, w = 1, h = 1): Pt {
  return { x: (tx + w / 2) * T, y: (ty + h / 2) * T };
}
/** World-px rect of a w×h tile block. */
export function tileRect(tx: number, ty: number, w: number, h: number): Rect {
  return { x: tx * T, y: ty * T, w: w * T, h: h * T };
}

// ---- painting chunks ----

/**
 * Pixel painting surface for one chunk. Coordinates are WORLD TILES (fractional ok);
 * implementations translate to chunk-local px with the one snapping rule:
 * x0 = round((tx - ox)·T), x1 = max(x0+1, round((tx - ox + w)·T)), same for y.
 */
export interface Paint {
  /** Fill a w×h tile rect. */
  tr(tx: number, ty: number, w: number, h: number, c: Color, a?: number): void;
  /** Fill an exact pixel rect: dx,dy,w,h in px, offset from tile (tx,ty)'s top-left. */
  p(tx: number, ty: number, dx: number, dy: number, w: number, h: number, c: Color, a?: number): void;
  /** Filled disc / ellipse as scanline spans; centre in world tiles, radii in px. */
  disc(tx: number, ty: number, r: number, c: Color, a?: number): void;
  ellipse(tx: number, ty: number, rx: number, ry: number, c: Color, a?: number): void;
}

/** Builders take WORLD TILE coordinates and store WORLD PX (centres via tileCentre). */
export interface FeatureBuilder {
  machine(kind: MachineKind, tx: number, ty: number, w: number, h: number): Machine;
  belt(tiles: ReadonlyArray<readonly [number, number]>, lanes: [Color[], Color[]]): BeltPath;
  inserter(tx: number, ty: number, dir: Dir, fast: boolean, beltId: string | null): Inserter;
  rail(a: readonly [number, number], b: readonly [number, number], lineId: string): RailSeg;
  station(tx: number, ty: number, lineId: string, vertical: boolean): Station;
  road(a: readonly [number, number], b: readonly [number, number], width: number): RoadSeg;
  wall(tx: number, ty: number, w: number, h: number): WallSeg;
  solar(tx: number, ty: number, w: number, h: number): SolarField;
  shore(tx: number, ty: number): void;
  /** Site builders take world-px geometry (use tileCentre/tileRect). */
  nest(s: Omit<NestSite, "id" | "cx" | "cy">): NestSite;
  outpost(s: Omit<OutpostSite, "id" | "cx" | "cy">): OutpostSite;
  hub(s: Omit<HubSite, "id" | "cx" | "cy">): HubSite;
  silo(s: Omit<SiloSite, "id" | "cx" | "cy">): SiloSite;
  readonly features: Features;
}

export type OreKind = "iron" | "copper" | "coal" | "stone";

/** Everything a district recipe may use. All coordinates are world tiles. */
export interface RecipeCtx extends Paint {
  readonly cx: number;
  readonly cy: number;
  readonly seed: number;
  readonly ox: number; // = cx * CH (world tile of the chunk's left edge)
  readonly oy: number; // = cy * CH
  readonly kind: DistrictKind;
  readonly landFrac: number;
  /** Sequential chunk RNG. Its call order is sacred once the look is approved. */
  rnd(): number;
  /** hash(x ?? cx, y ?? cy, seed + salt) in [0, 1). */
  h(salt: number, x?: number, y?: number): number;
  land(tx: number, ty: number): boolean; // valid for tiles within the apron
  shoreDist(tx: number, ty: number): number; // tiles to nearest water, capped at 9; 0 on water
  ore(tx: number, ty: number): OreKind | null;
  free(tx: number, ty: number, w: number, h: number): boolean; // all land, none reserved, inside chunk
  reserve(tx: number, ty: number, w: number, h: number): void;
  readonly feat: FeatureBuilder;
  /** Neighbour info for pairing rules (pure, via World.kindAt). */
  kindAt(cx: number, cy: number): DistrictKind;
}
export type Recipe = (ctx: RecipeCtx) => void;

// ---- runtime ----

export interface Rand {
  next(): number; // [0, 1)
  range(a: number, b: number): number; // [a, b)
  int(a: number, b: number): number; // integer in [a, b)
  pick<V>(arr: readonly V[]): V;
  chance(p: number): boolean;
}

/** World px → CSS px: sx = (wx - x0)·z. */
export interface View {
```

```ts
// Integer-mixing hash (bit-identical to akl.io's) and value noise. The
// only randomness chunk generation may use.

export function hash(x: number, y: number, s: number): number {
  let n = Math.imul(x | 0, 374761393) ^ Math.imul(y | 0, 668265263) ^ Math.imul((s | 0) + 1, 1274126177);
  n = Math.imul(n ^ (n >>> 13), 1103515245);
  n ^= n >>> 16;
  return (n >>> 0) / 4294967296;
}

export function vnoise(x: number, y: number, sc: number, s: number): number {
  const gx = x / sc,
    gy = y / sc,
    x0 = Math.floor(gx),
    y0 = Math.floor(gy);
  const fx = gx - x0,
    fy = gy - y0,
    u = fx * fx * (3 - 2 * fx),
    v = fy * fy * (3 - 2 * fy);
  return (
    (hash(x0, y0, s) * (1 - u) + hash(x0 + 1, y0, s) * u) * (1 - v) +
    (hash(x0, y0 + 1, s) * (1 - u) + hash(x0 + 1, y0 + 1, s) * u) * v
  );
}

/** Two-octave value noise in [0, 1], tile coordinates (akl:33). */
export function noise(x: number, y: number, s: number): number {
  return vnoise(x, y, 9, s) * 0.6 + vnoise(x + 61, y + 61, 3.3, s + 7) * 0.4;
}

/** Sequential per-chunk RNG: hash(cx, cy, seed + 1000 + k++). */
export function chunkRng(cx: number, cy: number, seed: number): () => number {
  let k = 0;
  return () => hash(cx, cy, seed + 1000 + k++);
}
```

```ts
// Pure RGBA raster that chunk recipes paint into (no Canvas2D in world/**).
// One snapping rule for every painter: see makePaint.
import { T, type Color, type Paint } from "./types";

const cache = new Map<string, [number, number, number, number]>();
export function parseColor(c: Color): [number, number, number, number] {
  const hit = cache.get(c);
  if (hit) return hit;
  let out: [number, number, number, number];
  if (c[0] === "#") {
    const h = c.slice(1);
    const full =
      h.length <= 4
        ? h
            .split("")
            .map((ch) => ch + ch)
            .join("")
        : h;
    out = [
      parseInt(full.slice(0, 2), 16),
      parseInt(full.slice(2, 4), 16),
      parseInt(full.slice(4, 6), 16),
      full.length >= 8 ? parseInt(full.slice(6, 8), 16) : 255,
    ];
  } else {
    const m = c.match(/rgba?\(([^)]+)\)/);
    if (!m) throw new Error(`bad colour ${c}`);
    const [r, g, b, a = "1"] = m[1].split(",").map((s) => s.trim());
    out = [+r, +g, +b, Math.round(+a * 255)];
  }
  cache.set(c, out);
  return out;
}

export class Raster {
  readonly data: Uint8ClampedArray;
  constructor(
    readonly w: number,
    readonly h: number,
  ) {
    this.data = new Uint8ClampedArray(w * h * 4);
  }
  /** Integer-pixel rect, clipped, source-over. */
  rect(x: number, y: number, w: number, h: number, c: Color, alpha = 1): void {
    const x0 = Math.max(0, x | 0),
      y0 = Math.max(0, y | 0);
    const x1 = Math.min(this.w, (x + w) | 0),
      y1 = Math.min(this.h, (y + h) | 0);
    if (x1 <= x0 || y1 <= y0) return;
    const [r, g, b, ca] = parseColor(c);
    const a = (ca / 255) * alpha;
    if (a <= 0) return;
    const d = this.data;
    if (a >= 1) {
      for (let yy = y0; yy < y1; yy++) {
        let i = (yy * this.w + x0) * 4;
        for (let xx = x0; xx < x1; xx++, i += 4) {
          d[i] = r;
          d[i + 1] = g;
          d[i + 2] = b;
          d[i + 3] = 255;
        }
      }
      return;
    }
    const ia = 1 - a;
    for (let yy = y0; yy < y1; yy++) {
      let i = (yy * this.w + x0) * 4;
      for (let xx = x0; xx < x1; xx++, i += 4) {
        d[i] = r * a + d[i] * ia + 0.5;
        d[i + 1] = g * a + d[i + 1] * ia + 0.5;
        d[i + 2] = b * a + d[i + 2] * ia + 0.5;
        d[i + 3] = 255 * a + d[i + 3] * ia + 0.5;
      }
    }
  }
}

/** Paint surface over a chunk raster whose top-left is world tile (ox, oy). */
export function makePaint(r: Raster, ox: number, oy: number): Paint {
  const X = (tx: number) => Math.round((tx - ox) * T);
  const Y = (ty: number) => Math.round((ty - oy) * T);
  const tr: Paint["tr"] = (tx, ty, w, h, c, a = 1) => {
    const x0 = X(tx),
      y0 = Y(ty);
    const x1 = Math.max(x0 + 1, X(tx + w)),
      y1 = Math.max(y0 + 1, Y(ty + h));
    r.rect(x0, y0, x1 - x0, y1 - y0, c, a);
  };
  const p: Paint["p"] = (tx, ty, dx, dy, w, h, c, a = 1) => {
    r.rect(
      X(tx) + Math.round(dx),
      Y(ty) + Math.round(dy),
      Math.max(1, Math.round(w)),
      Math.max(1, Math.round(h)),
      c,
      a,
    );
  };
  const ellipse: Paint["ellipse"] = (tx, ty, rx, ry, c, a = 1) => {
    const cx = X(tx),
      cy = Y(ty);
    for (let dy = -ry; dy < ry; dy++) {
      const yy = (dy + 0.5) / ry;
      const half = Math.round(rx * Math.sqrt(Math.max(0, 1 - yy * yy)));
      if (half > 0) r.rect(cx - half, cy + dy, half * 2, 1, c, a);
    }
  };
  const disc: Paint["disc"] = (tx, ty, rad, c, a = 1) => ellipse(tx, ty, rad, rad, c, a);
  return { tr, p, disc, ellipse };
}
```

```ts
    },
    evict(cx, cy) {
      w.resident.delete(key(cx, cy));
      w.epochs.set(key(cx, cy), (w.epochs.get(key(cx, cy)) ?? 0) + 1);
      w.generation++;
    },
    saveRect(r: Rect): OverlayToken | null {
      const cx = Math.floor(r.x / CPX),
        cy = Math.floor(r.y / CPX);
      if (!w.resident.has(key(cx, cy))) return null;
      return { cx, cy, epoch: w.epoch(cx, cy), rect: r };
    },
    paint(tok, fn) {
      if (w.epoch(tok.cx, tok.cy) !== tok.epoch) return false;
      w.painted++;
      fn(fakeContext(), tok.cx * CPX, tok.cy * CPX);
      return true;
    },
    restore(tok) {
      if (w.epoch(tok.cx, tok.cy) !== tok.epoch) return false;
      w.restored++;
      return true;
    },
  };
  return w;
}
```

```ts
  x: number; y: number; zoom: number; view: View; pinned: boolean;
  constructor(world: WorldQuery, rand: Rand, opts: { phone: boolean });
  setPhone(phone: boolean): void;          // base zoom 2.0 phone / 2.4 desktop
  setViewport(w: number, h: number, dpr: number): void; // css px
  update(dt: number, t: number, hints: CamHint[]): void;
  lookAt(p: Pt): void;                      // 14 s linger at p
  prefer(kind: DistrictKind | null): void;  // bias next POI toward kind
  reset(): void;                            // back to downtown
  geo(): string;                            // "47.6062° N · 122.3321° W · 2.4×"
  target(): Pt;                             // current waypoint (tests)
}
```
- Behaviour (handoff §6.4): start at `DOWNTOWN` (world px = tiles × T); waypoints: scan `world.kindAt` for chunks within 3 chunks of the current position and inside `CENTRAL_BOX`, preferring a `prefer()`ed kind, else a kind not among the last 4 waypoint kinds (one candidate per kind, nearest); else a random point in `CENTRAL_BOX` whose chunk has `landFracAt ≥ .6` (40 tries, else downtown). Linger `rand.range(9, 15)` s. Ease `1 − e^(−0.32·dt)`; `1 − e^(−0.9·dt)` while the top-priority hint has a `target`. Hold (no new waypoint) while any hint has `hold`. Zoom = base · (1 + .04·sin(.11t) + eased Σ`zoomOffset`), easing at 0.8/s. `view = { x0: x − w/(2z), y0: y − h/(2z), w, h, z: zoom, dpr }`. `pinned` → `update` changes nothing. `geo()` uses `toGeo(x/T, y/T)` with 4 decimals and `zoom.toFixed(1)`.

### Shared rules for event machines (Tasks 10–13)

- One class per file implementing `EventMachine`, constructor without required args unless stated; randomness only via `ctx.rand`; time via `ctx.t/ctx.dt`; no DOM; journal lines via `ctx.emit` with the **exact** strings from handoff §6.3 (numbers/ids substituted).
- Slow state accumulates on every update regardless of camera. Binding a site: `ctx.world.findSite(kind, { x: ctx.cam.x, y: ctx.cam.y }, 4)`; record `epoch = ctx.world.epoch(cx, cy)` once the chunk is resident; every update while bound, `ctx.world.epoch(cx, cy) !== epoch` → `reset()` silently. Site geometry comes from `ctx.world.query(chunk rect)` once `isResident`; until then, wait (≤ 20 s) with `camHint() = { target: site.centre, priority }`, then give up and re-arm.
- `findSite` null → re-arm 10–20 s later and report the needed kind via `wants()`.
- Ids in lines: `n = (Math.abs(cx * 7 + cy * 13) % 9) + 1` of the relevant chunk, or a counter. Not unique — flavour.
- `draw` renders the machine's own visuals with `d.sx/sy`, culls with `d.inView`, adds lights with `d.light`.
- Stats: add to per-step counters (`threats`, `bots`, `trains`) each update; increment cumulative fields on completion.
- Tests use `tests/fakes/ctx.ts` and `tests/fakes/world.ts`. Each machine's tests assert: (1) a full cycle produces the exact line sequence; (2) eviction mid-cycle resets silently; (3) `draw` does not throw in any state.

- **Kind selection** (`kindAt`, cached in a `Map`, FIFO-trimmed at 4096 entries):
  1. `b = chunkBase(cx, cy, seed)`; `landFrac < .35 → wild`; `landFrac < .72 → (oreCount > 90 ? mine : outpost)`.
  2. Otherwise `pick = ['smelt','asm','power','hub','asm','smelt','mine','asm','labs','solar','oil','storage','power','smelt','asm','hub'][⌊hash(cx,cy,seed+500)·16⌋]`; `silo` instead when `hash(cx,cy,seed+504) < 1/20`; mine rules as akl:110 (`oreCount > 180 || (oreCount > 60 && pick === 'mine')` → mine; else `pick === 'mine'` → asm).
  3. **Nest override** (spec §4.5.1, adjusted: a `wild` chunk with land ≥ .6 cannot occur after step 1, so the override applies to step-2 `asm|storage` chunks): base `asm|storage`, `landFrac ≥ .6`, `hash(cx,cy,seed+510) < 1/40`, and no base (steps 1–2) `hub` within Chebyshev distance 3 → `nest`.
  4. **Outpost pairing:** a nest's outpost = its 4-neighbour with `landFrac ≥ .6` nearest `DOWNTOWN` (ties N, E, S, W) — `pairedOutpost`. A chunk is `outpost` if any 4-neighbour is a nest whose `pairedOutpost` is this chunk (overrides steps 1–2).
- **Sacred order:** `paintRaster` = `chunkBase` → `RecipeCtx` (`rnd = chunkRng(cx,cy,seed)`) → `paintTerrain` → `paintCommon` → `RECIPES[kind](ctx)`. Salts: 1–8 terrain noise layers, 500–510 kind dice, 600+ recipe-local (each recipe lists its own).
- **`RecipeCtx`:** `makePaint(raster, ox, oy)` + `rnd`, `h`, `land`/`shoreDist` from the mask/dist with apron, `ore` from `ChunkBase`, a reservation grid (`free`/`reserve`, inside-chunk only), a `FeatureBuilder` assigning ids `${prefix}:${cx},${cy}:${n}` (prefixes: `m` machine, `b` belt, `i` inserter, `r` rail, `st` station, `rd` road, `w` wall, `s` solar, `n` nest, `o` outpost, `h` hub, `si` silo) and converting tile coords to world px, `kindAt` bound to the world.
- **`query`:** merge features of resident chunks overlapping the chunk-aligned rect; join `RailSeg`s with equal `lineId` whose endpoints touch, same for `RoadSeg`s; memo key `${cx0},${cy0},${cx1},${cy1}@${generation}` (keep the last 4).
- **`findSite`:** spiral over chunks within `maxChunks` (Chebyshev) of `from`'s chunk using `kindAt`; nearest wins (ties by spiral order).
- **Canvas:** `chunk()` = `paintRaster` + `canvasFactory()` sized `CPX×CPX` + `getContext('2d').putImageData(new ImageData(raster.data, CPX, CPX), 0, 0)` (guard: when `ImageData` is undefined — tests — skip `putImageData`); store features; `generation++`; `epoch++` for that key. Eviction takes the `Map` front, zeroes `canvas.width/height`, `generation++`.
- **`overlay.ts`:** `saveRect` → `getImageData` of the chunk-local rect stored in a `WeakMap<OverlayToken, ImageData>`; `paint` checks epoch then calls `fn(g, cx·CPX, cy·CPX)`; `restore` checks epoch then `putImageData`. Overlay is the only Canvas2D user in `world/`.
